## 🌐 Sobre o Projeto

O **software** é uma plataforma web desenvolvida para centralizar e otimizar o controle de estoque e a gestão das movimentações de materiais da empresa.

A solução foi projetada para atender às necessidades operacionais relacionadas ao armazenamento, distribuição e movimentação de materiais entre diferentes depósitos e obras.

O sistema permite acompanhar o estoque, registrar entradas e saídas, realizar transferências entre depósitos, identificar materiais em situação crítica e disponibilizar informações operacionais por meio de um painel centralizado.

O projeto é desenvolvido em parceria com a **Marmopedras**, tendo como objetivo fornecer uma solução tecnológica estruturada para utilização em um ambiente empresarial real.

---

## 🎯 Objetivos

O sistema possui como principais objetivos:

- Centralizar as informações relacionadas ao estoque;
- Reduzir processos manuais de controle;
- Aumentar a rastreabilidade das movimentações;
- Facilitar o acompanhamento dos materiais por depósito;
- Identificar rapidamente situações de estoque baixo ou crítico;
- Registrar entradas, saídas e transferências;
- Evitar movimentações incompatíveis com o saldo disponível;
- Apoiar a tomada de decisão operacional;
- Organizar informações provenientes do pré-atendimento comercial;
- Disponibilizar uma base tecnológica preparada para evolução contínua.

# 🛠️ Funcionalidades

### 📦 Gestão de Estoque

Permite consultar e acompanhar os materiais cadastrados no sistema.

Cada material pode possuir informações como:

- Nome;
- Código;
- Categoria;
- Unidade;
- Quantidade disponível;
- Depósito;
- Status do estoque;
- Informações complementares.

O sistema permite identificar a situação do estoque por meio de diferentes níveis:

- **Normal**
- **Baixo**
- **Crítico**

---

### 🔄 Movimentações

A plataforma permite registrar diferentes tipos de movimentações:

- Entrada de materiais;
- Saída de materiais para obras;
- Transferência entre depósitos.

As operações passam por validações antes de alterar os saldos armazenados.

---

### 🏢 Gestão de Depósitos

O sistema permite acompanhar a distribuição dos materiais entre os depósitos utilizados pela empresa.

É possível visualizar:

- Materiais armazenados;
- Quantidades disponíveis;
- Itens com estoque reduzido;
- Itens em situação crítica;
- Movimentações relacionadas ao depósito.

---

### 📋 Histórico de Movimentações

As movimentações realizadas ficam registradas para permitir maior rastreabilidade das operações.

O histórico possui recursos de:

- Pesquisa;
- Filtros;
- Período;
- Tipo de movimentação;
- Paginação;
- Consulta das operações realizadas.

---

### 📊 Painel Operacional

O painel principal apresenta informações relevantes para o acompanhamento das operações.

Entre os indicadores estão:

- Entradas realizadas;
- Saídas realizadas;
- Obras atendidas;
- Materiais com estoque baixo;
- Materiais em situação crítica;
- Movimentações recentes.

---

### 👤 Gestão de Usuários

A aplicação possui recursos relacionados ao gerenciamento de acesso dos usuários.

Entre eles:

- Cadastro;
- Autenticação;
- Login;
- Controle de acesso;
- Gerenciamento de usuários autorizados.
